📍 Ubicación

Agrupa lo importado por sesiones y pon ubicación a las fotos y vídeos que no la traen, para que Synology Photos las sitúe en el mapa.

{% endblock %} {% block content %}

1. Carpeta de la biblioteca

«Buscar archivos nuevos» añade al índice lo que aún no esté (por ejemplo, fotos importadas antes de que existiera este módulo). «Releer todo» vuelve a leer el EXIF de cada archivo, útil si el índice se ha quedado desfasado.

2. Sesiones detectadas

Una foto de las 9:00 se agrupa con toda la secuencia que sigue a esa hora; si luego disparas a las 11:00, eso ya es otra sesión. Puedes marcar varias sesiones a la vez para asignarles la misma ubicación.

3. Deducir ubicación desde referencias

Busca, para cada sesión sin ubicación, una referencia con GPS tomada a una hora cercana y propone su posición. Es una aproximación: se muestra siempre con cuánta diferencia de tiempo se dedujo.
